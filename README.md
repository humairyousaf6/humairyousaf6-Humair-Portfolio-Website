# Muhammad Humair — Portfolio

Personal portfolio of **Muhammad Humair**, AI/ML & Automation Engineer, covering LLMs, agentic AI, RAG, MCP, n8n automation and scalable machine learning systems.

## Live Website

**[humair.online](https://humair.online)**

## Highlights

- About, skills, and projects sections with project case studies
- Interactive particle animation in the contact section
- AI chatbot that answers questions about my work
- Contact form and downloadable resume

## Tech Stack

TanStack Start, React, TypeScript, Tailwind CSS, Framer Motion, Supabase, deployed on Cloudflare Workers.

## Run Locally

```bash
npm install
cp .env.example .env.local   # add your own API keys
npm run dev
```

Opens at `http://localhost:8080`.
